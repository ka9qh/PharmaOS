# ملاحظات شاشة التفعيل (نُفِّذت فعليًا في Phase 7 - راجع features/licensing)

**تحديث**: هذه الشاشة مبنية بالفعل الآن (`features/licensing/presentation/screens/licensing_screen.dart`)
وتعمل تلقائيًا كنقطة بداية للتطبيق إذا لم يوجد ترخيص صالح لهذا الجهاز
(راجع lib/main.dart وlib/app/app_router.dart).

سير العمل الفعلي:
1. عند أول تشغيل، تعرض الشاشة معرف الجهاز (Hardware ID) مع زر نسخ.
2. صاحب الصيدلية يرسل هذا المعرف لمزوّد النظام.
3. مزوّد النظام يشغّل `dart run tools/license_generator.dart <hwid> "<اسم الصيدلية>" [أيام الصلاحية]`
   على جهازه الخاص (هذه الأداة لا تُشحن أبدًا ضمن نسخة الصيدلية - راجع docs/LICENSE_GENERATOR_GUIDE.md).
4. صاحب الصيدلية يلصق مفتاح التفعيل الناتج ويضغط "تفعيل".
5. يُحفظ الترخيص محليًا في جدول licenses، ويُعاد التحقق من توقيعه ومطابقة
   معرف الجهاز في كل تشغيل لاحق للتطبيق (وليس فقط عند أول تفعيل).
