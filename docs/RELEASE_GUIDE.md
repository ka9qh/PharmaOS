# دليل إصدار نسخة جديدة لصيدلية - PharmaOS

1. بناء النسخة عبر BUILD_GUIDE.md.
2. أخذ Hardware ID من الصيدلية الجديدة.
3. توليد مفتاح ترخيص خاص بها (انظر LICENSING_STRATEGY.md).
4. تجهيز حزمة تثبيت تحتوي: ملف exe + مفتاح الترخيص + دليل تركيب مبسط للمستخدم النهائي.
5. تركيب فعلي على جهاز الصيدلية + اختبار الطابعة والقارئ سويًا.
6. تدريب الكاشير على الاستخدام الأساسي (10-15 دقيقة كافية إذا كانت الواجهة مصممة جيدًا).
