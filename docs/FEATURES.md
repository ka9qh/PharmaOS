# قائمة الميزات الكاملة - PharmaOS

انظر أيضًا PROJECT_ROADMAP.md لترتيب بناء هذه الميزات على مراحل.

1. Authentication - تسجيل الدخول والصلاحيات
2. Dashboard - الشاشة الرئيسية والمؤشرات
3. Inventory - إدارة المخزون (الأدوية، الفئات، الشركات، الدفعات)
4. Suppliers / Customers - الموردون والعملاء
5. Purchases - المشتريات من الموردين
6. Sales / POS - نقطة البيع
7. Returns - المرتجعات
8. Expenses - المصاريف
9. Accounting - المحاسبة العامة (الصندوق، الديون، التسديدات)
10. Reports - التقارير بأنواعها
11. Analytics (AI) - التحليلات الذكية القائمة على القواعد
12. Barcode - توليد وطباعة وقراءة الباركود
13. Backup - النسخ الاحتياطي والاستعادة
14. Settings - إعدادات النظام العامة
15. Users / Roles / Permissions - إدارة المستخدمين والصلاحيات
16. Notifications / Stock Alerts - التنبيهات ونواقص المخزون
17. Audit Logs - سجل التدقيق
18. Licensing - نظام الترخيص (لأن النظام منتج يُباع)
19. Hardware - تكامل طابعة الملصقات وقارئ الباركود
