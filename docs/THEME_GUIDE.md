# دليل الثيم البصري - PharmaOS

- تصميم Light Mode فقط في المرحلة الأولى (لا حاجة لـ Dark Mode في بيئة صيدلية).
- الألوان الأساسية: يُحدَّد لاحقًا حسب هوية كل صيدلية (قابل للتخصيص كمنتج قابل للبيع).
- الخط: خط عربي واضح وسهل القراءة تحت الإضاءة (مثل Cairo أو Tajawal) - يوضع في assets/fonts.
- أزرار العمليات الحساسة (حذف/إلغاء/إغلاق يومية) تكون دائمًا بلون تحذيري (أحمر/برتقالي) مع نافذة تأكيد إلزامية.
