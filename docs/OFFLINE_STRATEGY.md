# استراتيجية العمل دون إنترنت - PharmaOS

النظام لا يعتمد إطلاقًا على أي اتصال إنترنت أو خادم خارجي أو API خارجي.
- قاعدة البيانات: SQLite محلي مشفّر بالكامل على جهاز الصيدلية.
- التحديثات: تُنقل يدويًا عبر ملف/USB (انظر UPDATE_STRATEGY.md).
- الترخيص: يُفعَّل مرة واحدة أوفلاين بالكامل، دون أي تحقق دوري عبر الإنترنت.
- التحليلات الذكية: تُنفَّذ محليًا بقواعد ثابتة، دون إرسال أي بيانات لأي خادم.
- النسخ الاحتياطي: يُحفظ محليًا (قرص آخر/USB)، مع إمكانية إضافة مزامنة سحابية اختيارية مستقبلاً فقط إذا رغب صاحب الصيدلية بذلك صراحة.
