# PharmaOS

نظام إدارة صيدلية متكامل (ERP) يعمل بالكامل دون إنترنت (Offline-First)،
مصمم كمنتج قابل للبيع لعدة صيدليات في اليمن.

## المزايا الأساسية
- نقطة بيع (POS) سريعة عبر قارئ الباركود.
- إدارة مخزون كاملة مع تتبع الدفعات وتواريخ الصلاحية.
- توليد وطباعة باركود لكل دواء.
- إغلاق يومية تلقائي شامل (مبيعات، مصاريف، أرباح، مخزون، نسخة احتياطية، تقرير).
- محاسبة كاملة (مصاريف، تسديدات، ديون، صندوق).
- تقارير وتحليلات محلية دون أي اتصال إنترنت.
- أمان: تشفير كامل لقاعدة البيانات، صلاحيات حسب الدور، سجل تدقيق شامل.
- نظام ترخيص مستقل لكل صيدلية.

## الوثائق
راجع مجلد docs/ لكل التفاصيل الهندسية والتشغيلية. للتركيب والاستخدام اليومي
البسيط، راجع PHARMACY_INSTALLATION_GUIDE.md في جذر المشروع.

## حالة المشروع (بعد Phase 8)
**مكتمل وظيفيًا لكل ما ورد في الطلب الأصلي**: نقطة بيع بمنطق FEFO، مخزون
وباركود، مشتريات وموردون وتسديدات، مصاريف ومرتجعات، تقارير وإصدار نوبات، لوحة
تحكم وتنبيهات وتحليلات محلية، ترخيص أوفلاين، إدارة مستخدمين، اختبارات وحدة
للمنطق الحرج، وسكربت بناء نهائي بتشويه الكود.

**لم يُختبر بعد على جهاز Windows حقيقي من هذه المحادثة** - راجع
docs/QA_CHECKLIST.md قبل أي تسليم فعلي لأي صيدلية.

### فجوات معروفة بصراحة (لم تُبنَ بعد، ولم تُذكر صراحة في الطلب الأصلي)
- **Customers (العملاء)**: لا توجد شاشة لتتبع ديون/حسابات العملاء الآجلة -
  البيع حاليًا نقدي فقط. أضِفها كميزة منفصلة إذا احتجتها.
- **Settings (الإعدادات)**: لا توجد شاشة لتخصيص اسم/شعار الصيدلية أو العملة
  المعروضة (مكتوبة "ريال" ثابتة في كل الشاشات حاليًا).
- **بيع دواء منتهي الصلاحية**: النظام يُنبّه لكنه لا يمنع بيع دواء منتهي
  فعليًا من نقطة البيع - قرار تجاري متروك لك حاليًا.
- **آلية تحديث تلقائية عبر USB**: موثّقة في docs/UPDATE_STRATEGY.md لكن لم
  تُبنَ كأداة فعلية بعد.
- **مزامنة بين فروع متعددة**: خارج نطاق المشروع عمدًا (نظام أحادي الصيدلية
  حسب OFFLINE_STRATEGY.md) - يمكن إضافتها لاحقًا إذا احتجتها لصيدلية بعدة فروع.
