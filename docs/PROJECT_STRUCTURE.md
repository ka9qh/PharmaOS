# شجرة المشروع الكاملة - PharmaOS

راجع الشجرة الفعلية المرفقة (PROJECT_TREE.txt) المولّدة تلقائيًا من المشروع الحقيقي على القرص.
هذا الملف يُحدَّث يدويًا كلما أُضيف مجلد أو ميزة جديدة بشكل جوهري (وليس عند كل ملف Skeleton).

## تحديث Phase 7
تمت إضافة مجلد `tools/` في جذر المشروع (يحتوي `license_generator.dart`) -
خارج `lib/` عمدًا حتى لا يُدرَج ضمن أي نسخة مبنية للتوزيع. راجع
docs/LICENSE_GENERATOR_GUIDE.md.

## تحديث Phase 1
تمت إضافة مجلد `lib/core/di/` (يحتوي `service_locator.dart`) - لم يكن موجودًا
في هيكل Phase 0 الأصلي. هذا مثال فعلي على "تحديث تلقائي عند إضافة مجلد جوهري
جديد" كما ورد في القواعد الأصلية للمشروع.

## نظرة عامة على مستوى القمة
```
PharmaOS/
├── lib/
│   ├── app/          -> ربط التطبيق (Theme, Router, MaterialApp)
│   ├── core/         -> كل ما هو مشترك بين جميع الميزات (قاعدة بيانات، أمان، ترخيص، عتاد)
│   ├── features/     -> كل ميزة في مجلد مستقل بنمط Clean Architecture كامل
│   └── main.dart
├── docs/             -> كل وثائق المشروع (هذا الملف أحدها)
├── assets/           -> أيقونات، صور، خطوط
├── test/             -> اختبارات الوحدة
├── backups_local/    -> النسخ الاحتياطية المحلية (لا تُرفع لأي مستودع)
├── reports_output/   -> تقارير إغلاق اليومية PDF/Excel
├── pubspec.yaml
└── analysis_options.yaml
```
