# استراتيجية تحديث النظام بدون إنترنت (خاصة بكونه منتجًا يُباع)

نظرًا لأن النظام سيُوزَّع على عدة صيدليات، يجب آلية تحديث لا تعتمد على الإنترنت:

1. تُبنى نسخة جديدة من التطبيق (exe جديد) مركزيًا لديك.
2. تُنقل عبر USB لكل صيدلية، أو تُرسل كملف يقوم صاحب الصيدلية بتشغيله.
3. المُحدِّث (Updater) يستبدل ملف التطبيق التنفيذي فقط، ولا يمس ملف قاعدة البيانات المحلية إطلاقًا.
4. أي تغيير في بنية قاعدة البيانات يُطبَّق تلقائيًا عبر ملفات Migrations (انظر lib/core/database/migrations)
   عند أول تشغيل بعد التحديث، مع نسخة احتياطية إلزامية قبل تطبيق أي Migration.
5. رقم إصدار قاعدة البيانات يُخزَّن داخل القاعدة نفسها للتحقق من التوافق قبل أي ترحيل.
