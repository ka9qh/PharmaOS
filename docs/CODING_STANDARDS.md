# معايير كتابة الكود - PharmaOS

- لغة التسمية: أسماء المتغيرات والدوال بالإنجليزية دائمًا، التعليقات وواجهة المستخدم بالعربية.
- كل ملف يبدأ بتعليق يوضح الميزة (Feature) والطبقة (Layer) التي ينتمي إليها.
- ممنوع كتابة استعلامات SQL مباشرة داخل الشاشات (Presentation Layer).
- كل UseCase يقوم بعملية واحدة فقط ومحددة بوضوح (Single Responsibility).
- الأخطاء تُرمى دائمًا كـ AppException أو أحد أصنافها الفرعية (انظر core/errors)، وليس Exception عامة.
- أي عملية مالية أو حسابية تُنفَّذ بمعادلات صريحة في الكود، ولا يُعتمد على أي نموذج ذكاء اصطناعي لحساب الأرقام.
- عدم ترك أي TODO بدون وصف واضح لما يجب تنفيذه بالضبط.
