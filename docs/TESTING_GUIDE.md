# دليل الاختبار - PharmaOS

- اختبارات الوحدة (Unit Tests) إلزامية لكل UseCase في طبقة Domain، خصوصًا الحسابات المالية (day_closing، الأرباح، الخصومات).
- اختبار يدوي إلزامي لكل شاشة جديدة على جهاز حقيقي (Windows) قبل اعتبارها منتهية.
- اختبار سيناريو "قطع الكهرباء المفاجئ أثناء عملية بيع" - يجب ألا تُفقد أو تتكرر أي عملية.
- اختبار الطابعة والقارئ الفعليين إلزامي قبل تسليم أي صيدلية النسخة النهائية.
