# معالجة الأخطاء - PharmaOS

- كل خطأ متوقع (نفاد مخزون، ترخيص غير صالح، محاولة تعديل يوم مُغلق) يُرمى كـ AppException مخصص (انظر core/errors).
- تُعرض رسالة الخطأ للمستخدم بالعربية دائمًا، بصيغة مفهومة وليست رسالة تقنية.
- الأخطاء غير المتوقعة (استثناءات النظام) تُسجَّل في ملف Log محلي (core/services - يُبنى لاحقًا) لمراجعتها دون مقاطعة عمل الكاشير.
- أي خطأ أثناء إغلاق اليومية يوقف العملية بالكامل قبل حفظ أي جزء منها (Atomic Operation) - إما أن تكتمل كل الخطوات أو لا يُحفظ شيء.
