# دليل الأمان - PharmaOS

## 1. تشفير قاعدة البيانات
- SQLCipher إلزامي، لا يُسمح بحفظ أي بيانات في ملف SQLite غير مشفّر.
- مفتاح التشفير مشتق من معرف الجهاز (Hardware ID) + قيمة سرية داخل الكود المُشوَّه (Obfuscated).

## 2. صلاحيات المستخدمين (RBAC)
| الدور | يرى الأرباح | يعدل الأسعار | يحذف/يلغي فاتورة | يدير المستخدمين | POS |
|---|---|---|---|---|---|
| Owner | نعم | نعم | نعم | نعم | نعم |
| Manager | نعم | نعم | عبر إلغاء عكسي فقط | لا | نعم |
| Accountant | نعم | لا | لا | لا | لا |
| Cashier | لا | لا | لا | لا | نعم |
| Inventory Clerk | لا | لا | لا | لا | لا |

## 3. كلمات المرور
تُشفَّر عبر BCrypt (salt تلقائي)، ولا تُخزَّن أو تُطبع أو تُسجَّل في أي ملف نصي أو Log.

## 4. سجل التدقيق (Audit Log)
كل عملية من هذه القائمة إلزامية التسجيل: تعديل سعر، إلغاء فاتورة، تعديل مخزون يدوي،
تسجيل مصروف، تسديد لتاجر، تغيير صلاحيات مستخدم، حذف تقرير إغلاق/نوبة سابق (من المدير فقط -
لا يوجد "قفل" لليوم في هذا النظام؛ راجع docs/WORKFLOW.md للتفاصيل والسبب).
السجل غير قابل للتعديل أو الحذف من داخل التطبيق.

## 5. عدم الحذف المباشر
لا يوجد زر "حذف فاتورة" نهائيًا. كل إلغاء هو قيد عكسي جديد يحافظ على السجل الكامل للمحاسبة.

## 6. حماية الكود عند الإصدار النهائي
تفعيل Code Obfuscation عند بناء ملف exe النهائي:
`flutter build windows --obfuscate --split-debug-info=build/debug_info`

## 7. النسخ الاحتياطي
نسخ مرقّمة (Versioned)، ليست نسخة واحدة تُستبدل - حماية من تلف النسخة الأخيرة نفسها.

## 8. الترخيص
كل نسخة مرتبطة بمعرف جهاز فريد. لا يعمل ملف قاعدة بيانات منسوخ من جهاز آخر دون
مفتاح ترخيص مطابق لنفس الجهاز الجديد.
