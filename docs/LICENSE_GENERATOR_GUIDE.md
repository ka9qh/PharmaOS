# دليل أداة توليد التراخيص - PharmaOS

هذه الأداة (`tools/license_generator.dart`) للاستخدام الداخلي فقط على جهازك
أنت (كمزوّد النظام)، وليست جزءًا من التطبيق الذي يُثبَّت في أي صيدلية.

## لماذا هي آمنة تلقائيًا؟
`flutter build windows` يبني الملف التنفيذي النهائي من مجلد `lib/` فقط.
مجلد `tools/` بالكامل خارج `lib/`، لذلك لا يُدرَج أبدًا ضمن أي نسخة تُسلَّم
لأي صيدلية، دون الحاجة لأي إعداد إضافي أو استبعاد يدوي.

## طريقة الاستخدام

```
dart run tools/license_generator.dart <hardware_id> "<اسم الصيدلية>" [عدد الأيام]
```

### مثال: ترخيص دائم (بدون تاريخ انتهاء)
```
dart run tools/license_generator.dart "WMIC-1234-5678" "صيدلية النور"
```

### مثال: ترخيص سنوي (365 يومًا)
```
dart run tools/license_generator.dart "WMIC-1234-5678" "صيدلية النور" 365
```

الناتج: مفتاح تفعيل نصي طويل (صيغة `payload.signature`) تنسخه بالكامل
وترسله لصاحب الصيدلية ليلصقه في شاشة التفعيل.

## من أين يحصل صاحب الصيدلية على hardware_id؟
تظهر شاشة التفعيل تلقائيًا عند أول تشغيل للنظام (لأنه لا يوجد ترخيص محفوظ
بعد)، وتعرض معرف الجهاز مع زر نسخ - يرسله لك عبر أي وسيلة تواصل.

## قبل أي عملية بيع تجارية حقيقية
1. غيّر القيمة في `lib/core/licensing/license_secret.dart` لقيمة عشوائية
   طويلة خاصة بك (لا تشاركها في أي مكان علني، ولا ترفعها لأي مستودع عام).
2. فعّل Code Obfuscation عند بناء نسخة الإنتاج النهائية (راجع docs/BUILD_GUIDE.md)
   حتى يصعب استخراج هذه القيمة من الملف التنفيذي المُصرَّف.
3. احتفظ بنسخة من `tools/license_generator.dart` وسجل بكل التراخيص التي
   أصدرتها (رقم الجهاز، اسم الصيدلية، التاريخ) في مكان آمن خاص بك - النظام
   الحالي لا يحتفظ بسجل مركزي للتراخيص الصادرة (لأنه أوفلاين بالكامل، لا يوجد
   خادم مركزي أصلاً).

## حدود هذا النظام (بصراحة)
راجع docs/LICENSING_STRATEGY.md - هذا نظام حماية "جيد بما يكفي" لمنع النسخ
العرضي بين الصيدليات، وليس حماية غير قابلة للكسر من مستخدم تقني متمرّس يقوم
بهندسة عكسية كاملة للتطبيق.
