# سياسة المساهمة - PharmaOS

هذا مشروع تجاري خاص (Proprietary)، وليس مفتوح المصدر. هذا الملف يوثّق فقط اتفاقيات
العمل الداخلية عند الاستعانة بأي مطور إضافي مستقبلاً على المشروع:
- الالتزام الكامل بـ CODING_STANDARDS.md وNAMING_CONVENTION.md.
- عدم تعديل أي ملف خارج نطاق المهمة المطلوبة.
- توثيق أي قرار هندسي جديد في الوثيقة المناسبة قبل التنفيذ.
