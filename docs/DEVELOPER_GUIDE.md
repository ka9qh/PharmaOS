# دليل المطور - PharmaOS

## البدء
1. تثبيت Flutter SDK (قناة Stable) + دعم Windows Desktop.
2. `flutter pub get`
3. `flutter run -d windows`

## قبل إضافة أي ميزة جديدة
اقرأ ARCHITECTURE.md وDATABASE_DESIGN.md وWORKFLOW.md الخاصة بهذه الميزة تحديدًا.

## عند العمل مع الذكاء الاصطناعي (Claude) على هذا المشروع
- اذكر دائمًا اسم الميزة والملف بالضبط المطلوب تعديله.
- لا تطلب تعديل أكثر من ميزة واحدة في نفس الرسالة إلا إذا كانت مرتبطة ببعضها مباشرة.
- بعد كل تعديل، اطلب قائمة الملفات المتأثرة (جديدة/معدلة) للتأكد من عدم تغيير شيء غير مطلوب.
