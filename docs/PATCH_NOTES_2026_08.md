# ملاحظات هذه الدفعة (Patch) - أغسطس 2026

## أولاً: تصحيح مهم حول حالة المشروع

بعد فحص فعلي للملف الذي رفعته: المشروع **ليس** مجرد Skeleton فارغ كما يفترض
الماستر برومبت المرفق. هو بالفعل:
- ~30,000 سطر Dart عبر 343 ملف.
- 27 ميزة (feature) ببنية Clean Architecture كاملة (domain/data/presentation).
- قاعدة بيانات Drift مشفّرة فعليًا بـ 20 جدولاً حقيقيًا (مبيعات، مشتريات،
  مرتجعات، مصاريف، تسديدات، سجل تدقيق...).
- شاشات حقيقية تعمل: تسجيل الدخول، POS، لوحة التحكم، الأدوية، المخزون،
  الذكاء الاصطناعي (محادثة)، النسخ الاحتياطي، الإعدادات، إلخ.
- توثيق داخلي ضخم (docs/) يغطي كل جانب تقريبًا.

خارطة الطريق الداخلية (`docs/PROJECT_ROADMAP.md`) تصف المشروع كأنه في "Phase 0"
لكن الكود الفعلي متقدم أكثر من ذلك بكثير. لذلك بدل "البناء من الصفر" بحسب
الـ 10 مراحل في الماستر برومبت، عملت هذه الدفعة كـ **تدقيق + إصلاح فجوات فعلية**
موجودة في الكود، مطابقةً لتعديلاتك الثلاثة.

## ثانيًا: الملفات المعدّلة في هذه الدفعة ولماذا

| الملف | التعديل |
|---|---|
| `lib/core/database/app_database.dart` | تفعيل WAL Mode (كان مطلوبًا ولم يكن مفعّلاً) + فهارس بحث + جدول FTS5 اختياري (schemaVersion 1→2 مع onUpgrade آمن) |
| `lib/features/medicines/data/datasources/medicines_datasource.dart` | البحث أصبح داخل SQL (فهرس/FTS5) بدل تحميل الجدول كاملاً وفلترته في الذاكرة |
| `lib/features/medicines/data/repositories/medicines_repository_impl.dart` | حذف الفلترة اليدوية القديمة، تمرير searchQuery مباشرة لمصدر البيانات |
| `lib/app/app_router.dart` | إضافة مسار `/pos` كنقطة دخول حقيقية |
| `lib/features/auth/presentation/screens/auth_screen.dart` | التوجيه بعد الدخول أصبح لـ `/pos` بدل `/dashboard` |
| `lib/features/pos/presentation/screens/pos_screen.dart` | زر "لوحة التحكم" في الـ AppBar (لأن الشاشة أصبحت هي نقطة الدخول) + أنيميشن خفيف على نافذة نجاح البيع |
| `docs/PROJECT_ROADMAP.md` | إضافة قسم يوثّق هذه القرارات (لم يُحذف أي محتوى قديم) |

لم أعدّل `medicines_table.dart` عمدًا - الفهارس أُنشئت عبر SQL خام داخل
migration بدلاً من تعديل تعريف الجدول، حتى **لا تحتاج إعادة تشغيل
`build_runner`** لهذه الدفعة تحديدًا. أي ملف `.g.dart` لم يتغير.

## ثالثاً: كيفية التطبيق

1. انسخ كل ملف من هذه الحزمة إلى نفس المسار في مشروعك الأصلي (استبدال كامل
   للملفات المذكورة أعلاه فقط - لا شيء آخر تغيّر).
2. شغّل `flutter pub get` ثم `flutter run` أو `flutter build windows`.
3. **لم يتغيّر تعريف أي جدول Dart**، لذا لا حاجة نظريًا لإعادة توليد الكود
   (`build_runner`) في هذه الدفعة بالذات - إن ظهر خطأ غير متوقع، شغّل
   `dart run build_runner build --delete-conflicting-outputs` للتأكد.
4. **مهم**: هذه قاعدة بيانات موجودة أصلاً لديك على جهاز التطوير (schemaVersion
   1)؟ الترقية لـ schemaVersion 2 ستعمل تلقائيًا عبر `onUpgrade` عند أول فتح -
   لن تُحذف أي بيانات. إن كانت قاعدة بيانات تجريبية فقط، احذفها وابدأ نظيفًا
   لتفادي أي تعقيد غير ضروري في الاختبار.

## رابعاً: تحذير صادق - لم أستطع اختبار هذا فعليًا

بيئة العمل هذه لا تملك Flutter/Dart مثبتًا ولا اتصال إنترنت لتحميل الحزم، لذلك
لم أستطع تشغيل `flutter analyze` أو `build_runner` أو تجربة بناء فعلي. الكود
مبني بمطابقة دقيقة لأنماط الكود الموجودة فعليًا عندك (تحققت من أسماء الأعمدة
الفعلية في `app_database.g.dart` المولّد قبل كتابة أي SQL خام)، لكن رجاءً
شغّله واختبره، وأخبرني بأي خطأ فعلي حتى أصلحه مباشرة - خصوصًا نقطة FTS5
المذكورة في تعليقات `app_database.dart` (قد لا تكون مفعّلة في بناء sqlite3mc
المستخدم؛ الكود يتعامل مع هذا بأمان تلقائيًا لكن يستحق التحقق).

## خامساً: ملف الـ Assets (خطوط/صور/أصوات) - توضيح مهم

طلبت ملف assets يحتوي خطوط وصور وأصوات "حقيقية". بصراحة تامة: بيئة العمل هذه
لا تملك اتصال إنترنت (لا يمكنني تحميل ملفات خط أو صوت فعلية من الإنترنت) ولا
أداة توليد صور/أصوات. لا أستطيع وضع ملف خط أو صوت حقيقي في الحزمة بدون أحد
هذين. وضع ملف وهمي باسم خط مشهور سيكون أسوأ من عدم وضعه - سيكسر البناء إن
فعّلت pubspec.yaml عليه.

**البديل العملي**: `lib/app/app_theme.dart` عندك فيه بالفعل TODO ينتظر خط
Cairo تحديدًا. إليك كل ما تحتاجه لتفعيله بنفسك خلال دقيقتين:

1. حمّل الخط (مجاني ومرخّص SIL Open Font License) من:
   https://fonts.google.com/specimen/Cairo
2. ضع `Cairo-Regular.ttf` و `Cairo-Bold.ttf` داخل `assets/fonts/`.
3. أضف هذا لـ `pubspec.yaml` تحت `flutter:` (لا تضفه قبل وضع الملفين فعليًا،
   وإلا سيفشل البناء):
   ```yaml
   flutter:
     fonts:
       - family: Cairo
         fonts:
           - asset: assets/fonts/Cairo-Regular.ttf
           - asset: assets/fonts/Cairo-Bold.ttf
             weight: 700
   ```
4. في `lib/app/app_theme.dart`، أضف `fontFamily: 'Cairo'` داخل `ThemeData(...)`.

قل لي إذا رفعت الملفين وسأكتب لك الـ pubspec.yaml و app_theme.dart المعدّلين
فعليًا في دفعة قادمة. نفس الأمر للأصوات (لا يوجد كود حاليًا يتوقع ملفات صوت -
أخبرني أي تنبيهات تريد صوتًا لها - مثلاً صوت عند إتمام البيع - وأربطها بملف
صوت تزوّدني به أو ترشدني لمصدر مرخّص).
