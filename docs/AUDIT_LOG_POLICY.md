# سياسة سجل التدقيق - PharmaOS

## ماذا يُسجَّل إلزاميًا
تعديل سعر دواء، إلغاء/إرجاع فاتورة، تعديل كمية مخزون يدويًا، تسجيل مصروف،
تسديد لتاجر، إنشاء/تعطيل مستخدم، تغيير صلاحيات، حذف تقرير إغلاق/نوبة سابق.

## بنية السجل
لكل عملية: مَن (user_id)، ماذا (action_type + table + record_id)،
متى (timestamp)، القيمة قبل التعديل، القيمة بعد التعديل.

## قاعدة صارمة
هذا السجل Append-Only بالكامل - لا توجد أي واجهة أو دالة في النظام تسمح بتعديله أو حذفه،
حتى من حساب Owner. هو خط الدفاع الأخير عند أي نزاع أو شك في التلاعب بالبيانات.
