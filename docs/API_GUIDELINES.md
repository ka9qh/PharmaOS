# ملاحظة بخصوص API - PharmaOS

النظام لا يحتوي على أي API خارجي أو خادم (Server) بما أنه أوفلاين بالكامل.
هذا الملف موجود فقط كمرجع مستقبلي في حال أراد صاحب المشروع لاحقًا (اختياريًا وبقرار صريح)
إضافة تطبيق جوال للإدارة عن بعد أو مزامنة بين فروع متعددة - عندها فقط سيُصمَّم API REST محلي
داخل الشبكة الداخلية للصيدلية (Local Network)، دون أي اعتماد على إنترنت خارجي.
