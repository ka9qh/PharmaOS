# قائمة الفحص الشاملة قبل التسليم - PharmaOS

استخدم هذه القائمة **بالترتيب** بعد كل بناء جديد (build_release.bat) وقبل
تسليم النظام لأي صيدلية حقيقية. ضع علامة ✓ أمام كل بند بعد اختباره فعليًا على
جهاز Windows حقيقي.

## 1. التأسيس (Foundation)
- [ ] `flutter pub get` ينجح بدون أخطاء
- [ ] `dart run build_runner build --delete-conflicting-outputs` ينجح بدون أخطاء
- [ ] `flutter run -d windows` يفتح التطبيق بدون Crash
- [ ] قاعدة البيانات تُنشأ فعليًا على القرص (تحقق من مجلد AppData الخاص بالتطبيق)

## 2. الترخيص
- [ ] عند أول تشغيل تظهر شاشة التفعيل بمعرف جهاز حقيقي (ليس فارغًا)
- [ ] زر نسخ معرف الجهاز يعمل
- [ ] `dart run tools/license_generator.dart` يولّد مفتاحًا صحيحًا
- [ ] لصق المفتاح الصحيح ينقل لشاشة تسجيل الدخول
- [ ] إغلاق التطبيق وإعادة فتحه لا يطلب تفعيلًا مجددًا
- [ ] لصق مفتاح خاطئ/تالف يعرض رسالة خطأ واضحة ولا يكسر التطبيق

## 3. تسجيل الدخول
- [ ] الدخول بـ admin / admin123 ينجح وينقل للوحة التحكم
- [ ] اسم مستخدم أو كلمة مرور خاطئة تعرض رسالة خطأ عربية واضحة
- [ ] زر تسجيل الخروج يعيد لشاشة الدخول فعليًا

## 4. المخزون والباركود
- [ ] إضافة تصنيف وشركة جديدين تعمل
- [ ] إضافة دواء جديد يولّد SKU وباركود تلقائيًا (غير فارغين، غير مكررين)
- [ ] معاينة الباركود تظهر بصريًا وتُقرأ بقارئ باركود حقيقي بنجاح
- [ ] زر الطباعة يفتح نافذة طباعة ويندوز فعليًا (اختبر مع طابعة الملصقات الحقيقية)
- [ ] استلام كمية جديدة (دفعة) من شاشة المخزون يزيد الكمية المعروضة فعليًا

## 5. نقطة البيع (الأهم)
- [ ] مسح باركود دواء موجود يضيفه للسلة تلقائيًا (اختبر بقارئ باركود حقيقي)
- [ ] إدخال باركود يدويًا + Enter يعمل كبديل عن القارئ
- [ ] باركود غير موجود يعرض رسالة خطأ واضحة
- [ ] تعديل الكمية داخل السلة يرفض تجاوز المخزون المتاح
- [ ] الخصم يُطرح من الإجمالي بشكل صحيح
- [ ] **اختبار FEFO الحرج**: أضف دواءً بدفعتين بتاريخي انتهاء مختلفين، بِعه
      بكمية تتجاوز الدفعة الأولى، تحقق أن الدفعة الأقرب انتهاءً استُهلكت أولًا
- [ ] إتمام البيع ينشئ فاتورة برقم فريد (INV-yyyyMMdd-NNNN)
- [ ] طلب كمية أكبر من المتوفر كليًا يُرفض ولا يُنشئ أي فاتورة جزئية

## 6. المشتريات والموردون
- [ ] إضافة مورد جديد تعمل
- [ ] فاتورة شراء بعدة أصناف تنشئ دفعة (Batch) جديدة لكل صنف فعليًا
- [ ] المخزون يزيد بالكمية الصحيحة بعد فاتورة الشراء
- [ ] شاشة أرصدة الموردين تعرض المتبقي الصحيح (إجمالي - مدفوع)
- [ ] تسجيل تسديد لمورد يُنقص "المتبقي" فورًا

## 7. المصاريف والمرتجعات
- [ ] تسجيل مصروف يظهر في إجمالي مصاريف اليوم
- [ ] مرتجع عميل جزئي: تحقق أن حالة الفاتورة تصبح "مرتجعة جزئيًا" والمخزون يزيد
- [ ] محاولة إرجاع كمية أكبر من المسموح تُرفض بوضوح
- [ ] مرتجع مورد: تحقق أن المخزون ينقص بالقدر الصحيح

## 8. التقارير وإصدار النوبة
- [ ] المعاينة الحية تعرض أرقامًا صحيحة قبل الإصدار
- [ ] "إصدار تقرير الآن" ينشئ ملفي PDF وExcel فعليًا (افتحهما وتحقق من المحتوى)
- [ ] **حرِج**: بعد الإصدار، سجّل بيعًا جديدًا فورًا - يجب أن ينجح بدون أي رفض
- [ ] إصدار تقرير ثانٍ في نفس اليوم يعرض فقط أرقام الفترة الجديدة (وليس مكررة)
- [ ] نسخة احتياطية جديدة تُنشأ في مجلد backups فعليًا عند كل إصدار

## 9. لوحة التحكم والتنبيهات
- [ ] بطاقات الملخص تعرض أرقامًا حقيقية مطابقة لما في التقارير
- [ ] جرس الإشعارات يعرض عددًا صحيحًا عند وجود دواء تحت حد التنبيه
- [ ] "آخر العمليات" يعرض فعلاً آخر ما قمت به (بيع، مصروف، إلخ)
- [ ] الرؤى الذكية تعرض نصوصًا منطقية مطابقة للأرقام الفعلية

## 10. المستخدمون والصلاحيات
- [ ] حساب Owner يمكنه إضافة مستخدم جديد (كاشير) بنجاح
- [ ] تسجيل الدخول بحساب الكاشير الجديد يعمل
- [ ] حساب الكاشير **لا يرى** شاشة المستخدمين أو صلاحية تعطيل مستخدمين آخرين
- [ ] تعطيل مستخدم يمنعه من تسجيل الدخول لاحقًا

## 11. الأمان
- [ ] فتح مجلد بيانات التطبيق والتأكد أن ملف قاعدة البيانات لا يُفتح كنص عادي
      (يجب أن يكون مشفّرًا - جرّب فتحه بمحرر نصوص، يجب أن يظهر كبيانات ثنائية غير مفهومة)
- [ ] محاولة نسخ ملف قاعدة البيانات لجهاز آخر بدون ترخيص - يجب أن يبقى
      التطبيق يطلب تفعيلًا في الجهاز الجديد (الترخيص منفصل عن التشفير، راجع
      docs/LICENSING_STRATEGY.md)

## 12. البناء النهائي
- [ ] `build_release.bat` ينجح ويُنتج مجلد Release كاملاً
- [ ] نسخ مجلد Release بالكامل لجهاز آخر (بدون Flutter مثبَّت عليه) والتشغيل
      منه مباشرة - يجب أن يعمل التطبيق بدون أي رسائل خطأ عن ملفات ناقصة

---

**قاعدة عامة**: أي بند يفشل هنا، أرسل لي رسالة الخطأ **كاملة وحرفية كما ظهرت**
وسأصلحها بدقة. لا تحاول تخمين الحل بنفسك أولاً إذا لم تكن متأكدًا - الخطأ
الحرفي أسرع طريق لتشخيص دقيق.
