# إرشادات واجهة المستخدم - PharmaOS

- الاتجاه: RTL بالكامل (العربية اللغة الأساسية للواجهة).
- شاشة POS مصممة للسرعة القصوى: أقل عدد نقرات ممكن لإتمام عملية بيع (يُفضَّل أن يكتفي الكاشير بالباركود + Enter فقط في الحالة العادية).
- كل عملية حساسة (حذف/إلغاء/إغلاق يومية) تتطلب نافذة تأكيد صريحة.
- الأرقام المالية تُعرض دائمًا بخط أوضح وحجم أكبر من النصوص الوصفية.
- تنبيهات نقص المخزون تظهر بشارة حمراء واضحة في لوحة التحكم دون الحاجة للدخول لشاشة المخزون.
